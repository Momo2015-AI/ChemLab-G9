# 测试约定

## 自动化冒烟测试

`node tests/smoke.mjs` 对 `dist/ChemLab-G9.html` 构建产物在 Node 中进行最小 DOM 模拟，覆盖：

- 首页：30 天学习日卡片、初始进度 0/30、空复习队列不显示复习入口。
- Day01 学习页：练习表单、3 道题、情境自测、知识卡片。
- Day02：量筒读数与气密性两张交互配图渲染、16 道题、难度标签。
- 未开发天（Day03）显示"开发中"提示。
- 错题复习页：空状态与有数据时的重测表单。

修改 `src/`、`content/`、`quiz/` 后，先 `node scripts/validate-content.mjs` 校验数据，再 `node scripts/build-single.mjs` 重建，最后跑冒烟测试。

## 手工验收场景

- 离线双击打开 `index.html`，首页能看到 30 天导航网格与进度条（初始应为 0/30）。
- 点击 Day01 进入学习页，完成三道练习题；未全部作答时点击提交应看到"还有题目未作答"提示，不判分。
- 全部作答并提交后，查看得分与逐题解析；返回首页，Day01 卡片应显示"已完成 · 最佳 X/3"与尝试次数，进度条相应更新。
- 同一天重做一次，首页卡片应显示"尝试 2 次"，最佳得分取较高者；学习页头部显示最近完成日期。
- 刷新页面、重新打开浏览器后，Day01 完成状态与进度条数值应保持不变。
- 故意答错至少一题，返回首页应出现"错题复习"入口；进入复习页重测，答对的题提交后移出队列，答错的题保留在队列里。
- 点击 Day03（或任意 `ready: false` 的天数）应看到"内容还在开发中"的提示与返回首页链接，不出现空白页或控制台报错。
- 在 iPad 横竖屏（或对应尺寸的浏览器窗口）检查阅读排版、触控目标大小和选项选中态是否正常。
- 把 `dist/ChemLab-G9.html` 通过 AirDrop 传到 iPad，用 Safari 离线打开：首页、Day01/02、错题复习均应可用，断网无影响。
- 系统开启深色模式时页面应切换为深色；开启"减弱动态效果"时动画应停止。
