# 测试约定

第一阶段以手工验收为主，覆盖以下场景：

- 离线双击打开 `index.html`，首页能看到 30 天导航网格与进度条（初始应为 0/30）。
- 点击 Day01 进入学习页，完成三道练习题；未全部作答时点击提交应看到"还有题目未作答"提示，不判分。
- 全部作答并提交后，查看得分与逐题解析；返回首页，Day01 卡片应显示"已完成 · X/3"，进度条相应更新。
- 刷新页面、重新打开浏览器后，Day01 完成状态与进度条数值应保持不变。
- 故意答错至少一题，返回首页应出现"待复习"提示；再次进入 Day01 重做，复习队列应更新为最新一次的错题，不重复堆积。
- 点击 Day02（或任意 `ready: false` 的天数）应看到"内容还在开发中"的提示与返回首页链接，不出现空白页或控制台报错。
- 在 iPad 横竖屏（或对应尺寸的浏览器窗口）检查阅读排版、触控目标大小和选项选中态是否正常。
