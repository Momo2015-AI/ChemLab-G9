# ChemLab-G9 V3.1

面向暑假 30 天自学的九年级化学（人教版上册）iPad 单页学习系统。

## 当前阶段

V3.1：在 Day01 精品样章基础上，补齐首页导航、学习进度可视化、跨天错题复习与单文件离线打包，为 Day02--30 的批量内容生产打好可复用的基础设施。

## iPad 使用（单文件版）

直接把 `dist/ChemLab-G9.html` 传到 iPad（AirDrop / 文件 App / 微信等），用 Safari 打开即可离线学习，无需网络、无需安装、无需构建。单文件已内联全部样式、逻辑与已发布天内容，不依赖任何外部资源。

> 新内容发布后重新运行 `node scripts/build-single.mjs` 再替换旧文件即可。

## 本地开发预览

直接在浏览器打开 `index.html` 即可，开发模式不依赖构建工具或网络服务；不传参数时展示首页导航，`?day=01` 直接进入指定天数，`?view=review` 进入错题复习。

## 主要功能

- **首页导航**：`content/manifest.js` 维护 30 天清单（标题、所属模块、是否已可学习），首页按此渲染学习日网格；未开发的天数点击后会提示“开发中”，不会报错或空白。
- **进度可视化**：首页展示总体进度条（读屏友好）与模块完成环形图；每张学习日卡片显示最佳得分与尝试次数。
- **本地学习记录**：练习结果保存在 `localStorage`，键名以 `chemlab-g9:v3:` 开头；同一题多次作答记为尝试历史，最佳得分与最近日期可见。
- **跨天错题复习**：每次提交测验后，答错的题目（含题号、题干、作答时间）汇总进 `chemlab-g9:v3:review`，首页提示并可直接进入 `?view=review` 重测；答对的题移出队列，答错的继续保留。
- **题目难度标注**：每道练习题可标注 基础 / 提升 / 挑战，便于分层训练。
- **实验安全标注**：需要成人陪同的实验步骤会在标题旁显示醒目的“⚠️ 需成人陪同”徽章，而不只是埋在正文里。
- **情境自测**：每天可选配 `checkpoint`（用原生 `<details>/<summary>` 实现，无需额外脚本、天然支持键盘和触控），供学生先判断后看解析，不计入测验分数。
- **暗色模式**：跟随系统 `prefers-color-scheme` 自动切换，夜间学习不刺眼。

## 脚本

- `node scripts/validate-content.mjs`：校验 manifest / 每日内容 / 题目数据一致性（ready 天数配对、答案下标越界、必填字段、难度取值），批量生产内容前必跑。
- `node scripts/build-single.mjs`：把 manifest、已发布天的内容与题目、样式、逻辑全部内联为单个自包含 HTML，输出到 `dist/ChemLab-G9.html`。
- `node tests/smoke.mjs`：对构建产物做冒烟测试（首页、学习页、配图、复习页渲染）。

## 目录

- `docs/`：产品、课程、教学与数据规范，另有 `PARENT_GUIDE.md` 给家长的简短使用说明
- `src/`：界面样式、交互逻辑与内容加载 / 路由代码
- `content/manifest.js`：30 天清单与导航数据
- `content/days/`：每天的学习内容数据
- `quiz/`：每日练习与单元测验数据
- `scripts/`：内容校验与单文件构建脚本
- `assets/`：图片、图标、音频及字体资源
- `dist/`：构建产物（iPad 直接使用）
- `tests/`：自动化冒烟测试与手工验收用例说明
