# ChemLab-G9 V3.0

面向暑假 30 天自学的九年级化学（人教版上册）iPad 单页学习系统。

## 当前阶段

V3.0 Alpha：完成项目骨架、课程与教学规范，进入 Day01 精品样章开发。

## 本地预览

直接在浏览器打开 `index.html` 即可。第一阶段不依赖构建工具或网络服务。

## 目录

- `docs/`：产品、课程、教学与数据规范
- `src/`：界面样式、交互逻辑与内容加载代码
- `content/days/`：每天的学习内容数据
- `quiz/`：每日练习与单元测验数据
- `assets/`：图片、图标、音频及字体资源
- `tests/`：内容和交互的检查用例

## 开发顺序

1. Day01 精品样章（内容、界面、练习与学习记录）
2. 通用课程页面与题目组件
3. Day02--Day30 内容生产与单元复习
4. 综合测试、iPad 适配与离线验收
