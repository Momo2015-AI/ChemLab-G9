# ChemLab-G9 V3.0 项目规格

## 产品定位

ChemLab-G9 是一套运行于 iPad 浏览器的单 HTML 九年级化学上册自学系统，服务暑假 30 天的连续学习。它不把教材简单搬到屏幕上，而是以生活问题、观察、解释、探究和练习组织学习。

## 用户与场景

- 用户：即将进入九年级、化学基础为零或不稳的学生。
- 场景：每天 45--60 分钟独立学习；家长可在旁协助但不必讲授。
- 教材范围：人教版九年级化学上册的核心内容。

## 核心体验

每个 Day 均按统一节奏展开：

1. 一个来自生活的核心问题
2. 观察现象，区分事实与猜测
3. 用初中阶段可理解的语言解释
4. 实验探究（目的、用品、步骤、现象、结论、注意事项）
5. 教师提醒与常见误区
6. 中考链接
7. 基础、提升、挑战三级练习
8. 可复习的今日知识卡片

## 第一阶段范围

- 单 HTML 入口与可扩展的内容数据结构
- Day01「化学就在我们身边」精品样章
- 本地学习进度、完成状态与练习结果保存
- iPad 横竖屏阅读和触控可用性

## 非目标（第一阶段）

- 不接入账户、云同步、在线题库或人工批改。
- 不复制或展示受版权保护的教材原文、试卷全文或图片。
- 不要求真实化学实验；涉及操作时必须明确安全边界。

## 验收标准

- 无网络、无构建步骤可打开并学习 Day01。
- 每个内容区块可用键盘和触控访问，正文具备清晰层级。
- 练习可作答、判分并显示简明解析；刷新页面后结果仍在。
- 不把「现象」当作「结论」，不把氧气说成可燃物等基础科学错误。
