# 给家长的话

ChemLab-G9 设计给学生独立学习，家长的角色是陪伴和观察，不需要讲授化学知识。

## 每天大概怎么陪

- 每天学习约 45--60 分钟，建议固定一个时间段，减少中途被打断。
- 打开首页能看到孩子已完成的天数和进度条，不需要追问细节，看进度即可。
- 涉及「⚠️ 需成人陪同」标记的实验步骤，请在旁看护，尤其是用火、加热或接触玻璃器皿的环节。

## 孩子卡住时怎么帮

- 优先让孩子自己重新读一遍"今天的问题"和"教师提醒"，而不是直接给答案。
- 可以追问"你觉得这是现象还是结论？""证据够不够？"，帮助孩子自己理清思路。
- 测验答错不是坏事，页面会显示解析；错题会自动进入复习队列，后续复习日会用到，不需要家长额外记录。

## 关于数据

- 学习记录只保存在孩子使用的这台设备的浏览器里（不上传、不需要账号），换设备或清除浏览器数据会导致记录丢失，请留意。
- 如果孩子在共用设备上学习，建议不要清理浏览器缓存/数据，否则学习进度会重置。
