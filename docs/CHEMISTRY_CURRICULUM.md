# ChemLab-G9 九年级化学上册 30 天教学地图

| 模块 | 天数 | 主题 | 核心产出 |
| --- | --- | --- | --- |
| 开启化学之门 | 01--03 | 化学与生活、实验室、安全、科学探究 | 能观察、记录、提出可验证问题 |
| 我们周围的空气 | 04--08 | 空气、氧气、制取、物质分类、复习 | 认识氧气及实验基本逻辑 |
| 物质构成的奥秘 | 09--15 | 分子原子、原子结构、元素、离子、周期表、化学式、复习 | 建立微观—符号—宏观联系 |
| 自然界的水 | 16--18 | 水的组成、水的净化、爱护水资源 | 解释水的变化与净化方法 |
| 化学方程式 | 19--23 | 质量守恒、方程式书写、配平、计算、复习 | 用化学方程式表达和计算变化 |
| 碳和碳的氧化物 | 24--27 | 碳单质、二氧化碳制取与性质、一氧化碳、复习 | 连接能源、环境与生命 |
| 燃料及其利用 | 28--29 | 燃烧灭火、燃料、能源与环境 | 用化学观点处理安全和能源问题 |
| 综合提升 | 30 | 全册知识网络与诊断 | 输出一张可视化知识网络图与个人错题清单，明确下一阶段复习重点 |

## Day01--03

- Day01：化学就在我们身边——判断变化，练习观察蜡烛燃烧。
- Day02：化学实验室探秘——认识仪器、基本操作与安全规则。
- Day03：科学探究方法——从问题到结论，辨析证据是否充分。

后续每个 Day 在对应内容文件中落实核心问题、实验、误区、题目与复习卡片。

## Day30

- 汇总 30 天的知识卡片，按模块组织成一张可视化知识网络图（而非逐日堆砌）。
- 基于本地保存的练习记录，生成个人错题清单，标注需要在开学后优先复习的知识点。
- 不引入新知识点，聚焦查漏补缺与自我诊断。
