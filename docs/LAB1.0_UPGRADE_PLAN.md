# ChemLab-G9 LAB1.0 Upgrade Plan

## Goal

Upgrade ChemLab-G9 from a learning content viewer into a complete junior high chemistry self-learning coach.

## 1. Knowledge model

Each knowledge point follows:

1. Phenomenon: what students observe
2. Concept: what it is
3. Micro explanation: why it happens
4. Application: where it is used
5. Exam point: how it is tested

## 2. Experiment model

Each experiment contains:

- Objective
- Question
- Hypothesis
- Design
- Observation
- Conclusion
- Error analysis
- Exam transfer

## 3. Question system

Question categories:

- Basic knowledge
- Concept understanding
- Experimental inquiry
- Comprehensive exam practice

Each question should contain:

- topic
- difficulty
- errorType
- explanation
- examPoint

## 4. Learning feedback

Daily learning loop:

Goal -> Learn -> Experiment -> Quiz -> Report -> Recommendation

## 5. Error diagnosis

Wrong answers should map to:

- Concept confusion
- Experimental method
- Equation writing
- Calculation ability
- Reading mistakes

## 6. Product principles

- Keep lightweight static architecture
- Keep offline support
- Optimize iPad experience
- Avoid unnecessary frameworks
